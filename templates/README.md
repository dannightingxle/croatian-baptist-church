# Elementor Templates

Place exported Elementor template `.json` files here. They'll be imported into the WordPress library by `scripts/import-templates.sh`.

## How to export a template from Elementor

1. Open a page in Elementor.
2. Click the folder icon (Templates) > **Save as Template**.
3. Go to **Templates > Saved Templates** in WP admin.
4. Hover the template and click **Export Template** — downloads a `.json` file.
5. Drop that `.json` into this folder and commit it.

## How to apply a template to a page

1. Open the page in Elementor.
2. Click the folder icon > **My Templates** tab.
3. Find the template and click **Insert**.
