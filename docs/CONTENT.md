# Content We Need From Ratimir

Send this list as-is to the pastor. Each item is what we need to actually build the pages out. **All text should be provided in Croatian.** We'll translate to English afterward (or he can if his English is strong).

## 1. Basics

- [ ] Full name of the church (Croatian + English)
- [ ] Short tagline (one sentence — what the church is about)
- [ ] Logo, if one exists. If not, we'll choose a simple typographic mark together.
- [ ] Primary brand colour, if any preference. Otherwise we'll pick something warm and timeless.

## 2. Contact

- [ ] Street address
- [ ] City, postal code
- [ ] Phone number(s)
- [ ] Email address
- [ ] Google Maps link to the building

## 3. Service times

- [ ] What day(s) do you meet?
- [ ] What time?
- [ ] Are there separate Bible study / prayer / youth meetings? When?
- [ ] Anything special visitors should know? (parking, children, language used, etc.)

## 4. About the church

- [ ] A paragraph (200–400 words) introducing the church. Who it's for, what makes it distinctive, the warmth of the community.
- [ ] Brief history — when was it founded? Any key moments?
- [ ] How big is the congregation (rough number)?

## 5. About the pastor

- [ ] Pastor's full name
- [ ] A photo (head-and-shoulders, friendly)
- [ ] 2–3 paragraph bio: training, family, how he came to ministry, what he loves about pastoring this church

## 6. Beliefs / Statement of Faith

- [ ] Either: write 5–10 short bullet points covering the church's core beliefs (Bible, God, Jesus, salvation, baptism, etc.)
- [ ] Or: link to an existing statement of faith we can use (e.g. Baptist World Alliance, Croatian Baptist Union)

## 7. Photos

- [ ] 5–10 photos of:
  - The building exterior
  - The interior during a service
  - The congregation gathered (smiling, candid, no posed shots if possible)
  - Anything else that conveys what the church is like

  Phone photos are fine. Higher resolution = better. Avoid heavily filtered ones.

## 8. Social media

- [ ] Facebook page URL (if exists)
- [ ] Instagram URL (if exists)
- [ ] YouTube / Vimeo channel for sermons (if exists)
- [ ] WhatsApp community link (if exists)

## 9. Optional but useful

- [ ] Any upcoming events / camps / conferences worth highlighting
- [ ] A short welcome video from the pastor (phone-recorded is fine, 60 seconds)
- [ ] Newsletter / mailing list — do they have one? Should we add a signup?
